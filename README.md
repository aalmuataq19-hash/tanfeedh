# مدارسة نظام التنفيذ ولائحته التنفيذية

موقع ثابت لقراءة نظام التنفيذ (المرسوم الملكي م/237 وتاريخ 1447/11/3هـ) ولائحته التنفيذية (قرار وزير العدل 617 وتاريخ 1448/5/7هـ) ومدارستهما، مرتبًا على المواد داخل أبوابها وفصولها.

الرابط: https://aalmuataq19-hash.github.io/tanfeedh/

## مكونات الموقع

| الملف | محتواه |
|---|---|
| `index.html` | هيكل الصفحة |
| `assets/site.css` | التصميم |
| `assets/app.js` | التوجيه والفهرس والبحث والعرض |
| `assets/fonts/` | خط IBM Plex Sans Arabic (رخصة OFL) |
| `data/structure.json` | الأبواب والفصول وأرقام المواد |
| `data/law.json` | نصوص مواد النظام (65 مادة) |
| `data/regulation.json` | نصوص مواد اللائحة (54 مادة)، وفي كل مادة `host` = رقم المادة النظامية التي تُعرض تحتها |
| `data/instruments.json` | المرسوم الملكي، وقرار مجلس الوزراء، وقرار إصدار اللائحة |
| `data/references.json` | نصوص الأنظمة الأخرى المرتبطة (مثل مواد نظام المعاملات المدنية) ومصادرها |
| `data/studies/N.json` | المادة العلمية للمادة رقم N |
| `data/studies/index.json` | قائمة المواد التي اكتملت مادتها العلمية |

النصوص الرسمية منقولة حرفيًّا من النسخة المنسقة (تنسيق: د. يونس بن سليمان الصالح)، ومع كل نص رقم صفحته.

## إضافة المادة العلمية لمادة جديدة

1. أنشئ الملف `data/studies/N.json` على مثال `data/studies/11.json`.
2. أضف رقم المادة إلى `data/studies/index.json`، مثل: `{"studies":[11, 12]}`.
3. لا يحتاج ذلك إلى أي تعديل في الواجهة.

أقسام الملف (`sections`) بالترتيب: `explain` الشرح، `new` الجديد وأثره العملي، `links` الروابط، `cases` التطبيق، `questions` مسائل المدارسة، `summary` الخلاصة العملية، `refs` المراجع.

### الترميز داخل النصوص العلمية

| الترميز | معناه |
|---|---|
| `{{م:13}}` | رابط إلى المادة (13) من النظام |
| `{{م:13\|الفقرة (1) من المادة (13)}}` | الرابط نفسه بعبارة مخصوصة |
| `{{ل:12}}` | رابط إلى المادة (12) من اللائحة |
| `{{ر:ctl295}}` | رابط إلى بطاقة نص من نظام آخر معرّف في `references.json` |
| `{{س:q8\|المسألة (8)}}` | رابط إلى مسألة في المادة نفسها |
| `**نص**` | تمييز بخط ثقيل |

### الوسوم

`explicit` نص صريح، `inferred` فهم مستنبط، `research` محل بحث، `proposed` رأي مقترح.

### أنواع الأسئلة

`فهم` و`تطبيق` (جوابهما في `a`)، و`مدارسة` (الآراء في `views`، والقدر المتفق عليه في `common`، والرأي المقترح في `proposed`، وتظهر تحتها خانة «ما انتهى إليه المجلس»).

## الروابط الثابتة

- المادة: `#/article/11`
- مادة اللائحة تحت مادتها: `#/article/11/r12`
- قسم من المادة العلمية: `#/article/11/sec-links`
- مسألة: `#/article/11/q8`
- أداة الإصدار: `#/instruments/decree`
- المنهجية: `#/about`
